PROJECT

Fully Connected Neural Network

NumPy 기반 신경망을 직접 구현하여 순전파와 역전파 내부 동작을 검증한 프로젝트.

프로젝트 개요

고수준 딥러닝 프레임워크에 의존하지 않고 Layer, Activation, Loss, Optimizer를 직접 구현해 신경망 연산 구조를 코드 수준에서 분석합니다.

핵심 구현

  • Forward / Backpropagation 직접 구현
  • ReLU, Sigmoid, Softmax 구현
  • CrossEntropy, MSE 구현
  • GD 및 단위 테스트 구성

기술 스택

Python, NumPy, Pytest, OOP

설계 및 개선 포인트

Layer·Neuron·Activation·Loss·Optimizer의 책임을 분리하고, Forward → Backpropagation → Gradient Update 흐름을 객체 구조로 설계했습니다. 역전파의 Error 전달과 Weight·Bias Gradient 계산을 직접 구현하여 딥러닝 학습 원리를 코드 수준에서 검증할 수 있도록 구성했습니다.
