PROJECT

Decoder-only SLM

PyTorch 기반 Decoder-only 언어모델 학습·검증 파이프라인 구현 프로젝트.

프로젝트 개요

Tokenizer부터 Transformer Decoder, DataLoader, 학습 및 검증 루프까지 직접 구성해 소형 언어모델 학습 흐름을 검증합니다.

핵심 구현

  • SentencePiece BPE 기반 토크나이저 구성
  • Causal Mask 기반 자기회귀 학습
  • Train / Validation 분리 및 Best Model 저장
  • Loss / Accuracy 기반 학습 상태 분석

기술 스택

Python, PyTorch, SentencePiece, Transformer

설계 및 개선 포인트

단순 기능 구현보다 구조적 의사결정, 테스트 가능성, 재사용성과 운영 확장성을 중심으로 설명합니다. 실제 수치가 확보된 경우 처리시간, 정확도, 메모리 사용량, 테스트 커버리지 등의 지표를 추가합니다.
