PROJECT

RAG & Agent Service

검색 증강 생성과 Agent 흐름을 실제 서비스 아키텍처로 확장하는 프로젝트.

프로젝트 개요

문서 검색, Vector DB, LLM 응답 생성, Agent 상태 흐름과 API 계층을 분리해 확장 가능한 서비스 구성을 목표로 합니다.

핵심 구현

  • 문서 검색 및 검색 결과 조합
  • LLM 응답 생성 파이프라인
  • Agent 상태 및 노드 흐름 설계
  • REST API 기반 서비스 연결

기술 스택

Python, LangChain, LangGraph, Vector DB, FastAPI

설계 및 개선 포인트

Architecture Style, Design Approach, Design Role, GoF Design Pattern 순으로 구조를 구체화하고, 구현과 검증을 반복하며 설계를 개선합니다.
