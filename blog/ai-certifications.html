AI CERTIFICATION

AI 개발자를 위한 자격증 및 온라인 교육과정

무료 또는 저비용 공식 온라인 학습 경로를 중심으로 ML Engineering, 생성형 AI, RAG, Agent 개발과 연관된 자격을 정리합니다.

기준

추천 학습 순서

  1. Microsoft AI-103 — 무료 공식 학습으로 생성형 AI와 Agent 개발 기반 확보
  2. AWS Machine Learning Engineer – Associate — ML Engineering 및 MLOps 역량 강화
  3. NVIDIA NCA-GENL — Transformer, LLM, RAG 중심의 전문성 보강
  4. Google Professional Machine Learning Engineer — Cloud ML 설계·운영 역량 확장
  5. Databricks Generative AI Engineer Associate — 데이터 플랫폼 기반 RAG/LLMOps 역량 보강

선택 기준

  • 무료 학습 우선: Microsoft Learn
  • ML Engineer 직무 중심: AWS Machine Learning Engineer – Associate
  • LLM/RAG 중심: NVIDIA NCA-GENL
  • Cloud ML 전문성: Google Professional Machine Learning Engineer
  • RAG/Data/LLMOps: Databricks Generative AI Engineer Associate

주의사항

자격시험 명칭, 시험 코드, 비용, 지원 언어 및 시험 범위는 변경될 수 있으므로 실제 응시 전 각 벤더의 공식 Certification 페이지에서 최신 정보를 다시 확인하는 것이 필요합니다.
