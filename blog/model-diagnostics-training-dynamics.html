DEEP LEARNING / MODEL DIAGNOSTICS

Weight · Gradient · Activation으로 모델을 읽는 법

모델 성능 개선을 architecture 변경이나 hyperparameter search만으로 접근하지 않고, 학습 과정에서 실제로 어떤 parameter와 neuron이 움직이고 있는지를 관찰하는 관점으로 정리합니다.

흥미로운 관점: 성능 개선을 “구조 변경”보다 “학습 상태 진단”에서 시작하기

Loss와 accuracy는 결과 지표입니다. 그 아래에서는 weight가 얼마나 바뀌는지, gradient가 각 layer까지 충분히 전달되는지, activation이 실제 입력에 반응하는지가 학습의 상태를 결정합니다. 따라서 성능 정체를 발견했을 때 바로 layer를 추가하거나 optimizer를 교체하기보다, 먼저 학습 신호의 흐름을 측정하는 접근이 유용합니다.

1 · Weight Parameter가 실제로 얼마나 업데이트되는가?

Weight norm, update magnitude, ΔW/W 등을 layer 또는 neuron 단위로 비교합니다.

2 · Gradient 학습 신호가 어디에서 약해지거나 커지는가?

Gradient norm과 분포를 통해 vanishing / exploding gradient 및 정체 구간을 찾습니다.

3 · Activation 뉴런이 실제 데이터에 반응하고 있는가?

Activation rate, mean, variance, saturation 등을 관찰하여 inactive 또는 과도하게 포화된 뉴런을 확인합니다.

4 · Training Dynamics 한 시점이 아니라 epoch에 따른 변화로 해석하기

Loss/metric과 내부 통계를 함께 추적하여 성능 변화의 원인을 시간축에서 분석합니다.

분석 순서

Validation metric 확인 → activation distribution → gradient flow → weight/update ratio → initialization·normalization·learning rate·optimizer·regularization 검토 순으로 접근하면, 변경의 근거를 남기기 쉽습니다.
